# Support

Use the channel that matches what you need:

- [Discord](https://discord.gg/kdjzykMTHJ): short build questions, comparing
  approaches, sharing what you made.
- [Developer documentation](https://docs.omnidim.io/docs): product, API, SDK,
  and dashboard references.
- [Service status](https://status.omnidim.io): current and past incidents.
- GitHub issues on the repository in question: reproducible bugs and concrete
  improvements.
- [support@omnidim.io](mailto:support@omnidim.io): account, billing, and
  anything that does not belong in public.

Do not include API keys, call recordings, customer data, or internal URLs in a
public post or issue.
